# PyUI-Lite + Sequencer Demo

A lightweight PyQt6 widget library + a grid-based sequencer app for playback demos. 

## Widgets
- RotaryKnob (0–100 drag control)
- StatusLED (on/off indicator)
- ProgressRing (circular progress bar)

## Demo App
- Drag-and-drop grid sequencer
- Playback controls
- Save/load via JSON
